## 信息架构

```
产品空间选择器（顶部，切换产品）
└── 四职能导航（左侧）
    ├── 需求     → 用户故事地图看板（活动层×任务层×版本行）
    ├── 规格     → 事件风暴画布
    ├── 开发     → 开发任务看板
    ├── 验收     → 验收清单
    └── 运营     → 运营观测
```

需求屏内部结构（用户故事地图）：

```
活动层（橙，跨列合并）
任务层（紫）
版本行 × N（MVP / 未来迭代，可折叠）
  └── 故事卡片 × N（白底，标题）
```

## 交互设计状态

**成熟度**：打磨中（骨架完整，细节有已知问题）

### 已知问题

| 问题 | 用户影响 | 来源 |
|------|---------|------|
| 矩阵层级绑定缺失——列头/泳道/卡片区无容器绑定，看不出列 | 地图阅读成本高，层级关系模糊 | context：interaction-experience-issues.md |
| 卡片信息缺失——只有标题，无状态/描述/操作暗示 | 无法区分与管理卡片，看板退化为示意图 | context：interaction-experience-issues.md |
| 文案重复（"验收验收"）与品牌标题三处重复 | 同屏概念混淆 | context：ui-ux-analysis-2026-08-21.md |
| 大面积空白（空列无提示） | 空状态含义不明 | context：ui-ux-analysis-2026-08-21.md |

### 迭代方向

1. 卡片信息增强（状态色点 + 描述摘要 + 交互暗示）
2. 矩阵层级绑定（列容器/色带）
3. 空状态处理、文案修正
