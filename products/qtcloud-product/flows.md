# QtCloud Product 用户流程

> 采集自 product.cloud.quanttide.com 实际界面 + 需求地图（2026-08-21）

## 流程一：登记新产品

```
触发：进入需求屏 → 产品清单
步骤：
  1. 打开产品清单（管理产品清单任务）
  2. 登记新产品（名称、状态、负责人）
  3. 产品出现在清单与产品空间选择器
完成：产品可被选择进入管理
```

## 流程二：梳理用户故事地图

```
触发：需求屏 → 选择产品空间
步骤：
  1. 看到故事地图看板（活动层/任务层/版本行）
  2. 在任务列中浏览故事卡片
  3. （编辑）拖拽/长按卡片调整归属
分支：
  - MVP 版本行：当前版本范围
  - 未来迭代行：后续规划
完成：地图结构确定
```

## 流程三：推进开发

```
触发：开发职能页
步骤：
  1. 查看开发任务看板
  2. 任务状态流转（To Do → In Progress → Review → Done）
  3. 卡片状态变化反映在地图
完成：功能进入验收
```

## 流程四：验收

```
触发：验收职能页
步骤：
  1. 查看验收清单
  2. 逐项验证用例
  3. 标记通过/不通过
完成：验收结果作为交付依据
```

## 流程五：运营观测

```
触发：运营职能页
步骤：
  1. 查看运营数据
  2. 基于数据调整产品结构
完成：数据驱动迭代
```
