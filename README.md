# 量潮交互设计档案

本仓库是量潮第二大脑中交互设计领域的**档案层**（陈述型记忆九宫格：现在 × 语义类），沉淀交互设计领域当前「相信什么知识」——即不断收敛的统一交互设计语言。

> **领域使命**：整合来自各个产品的交互设计经验，形成一套统一的交互设计语言——而不是各个产品各自为战。各产品是经验的实践场，本领域是经验的整合场。本仓库是该使命在知识层的落点。

## 与 data/ 其他子模块的分工

| 子模块 | 九宫格位置 | 承载内容 |
|--------|-----------|----------|
| `data/context` | Context（工作语境） | 交互设计领域的概念与背景 |
| `data/journal` | Journal（工作日志，现在×事件类） | 交互设计实践的流水记录 |
| `data/profile` | Profile（工作档案，现在×语义类，本仓库） | 交互设计语言：术语、组件、模式、原则、规范 |
| `data/intention` | Intention（工作意图，未来×自我类） | 交互设计领域的使命与目标 |

## 目录结构

```
profile/
├── README.md       # 本文件
├── AGENTS.md       # 建设规范
├── language/       # 交互设计语言——统一语言的实际载体
│   └── README.md   # 语言目录说明（术语、组件、模式、原则、规范）
└── products/       # 各产品交互设计档案——语言提炼的素材来源
    └── README.md   # 档案目录说明（目录名与领域仓库 apps/ 子模块名一致）
```

## 维护规范

1. **以实际产品为准** — 档案从各产品（`apps/`）的实际界面与交互采集，而不是凭空设计
2. **产品即目录** — 每个产品一个目录，目录名与领域仓库 `apps/` 子模块名保持一致
3. **档案提炼语言** — 从 `products/` 的实践素材提炼统一设计语言，沉淀进 `language/`，固化后回流 `packages/quanttide-design-toolkit`
