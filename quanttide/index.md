# 量潮设计语言

从Material Design出发逐渐演化一套自己的量潮设计语言，总结于各个应用的实践。

## 列表–详情工作台（Master–Detail）

内容生产类应用（工作室型）的统一三栏骨架，源自 qtcloud-media-studio 的实践：

- **栏序**：导航栏（icon + 文字，窄）→ 列表面板（list panel，中）→ 详情区（编辑/预览，宽）
- **无顶栏**：设计中不设顶部栏，应用名不进界面；操作按归属分布在侧边（导航栏、列表面板）与详情工具带
- **等高**：列表面板通栏，与导航栏同高
- **设置沉底**：设置入口放导航栏底部、与内容分区拉开间距；设置不是分区
- **归属原则：动作作用于谁，就住哪一栏**——动「当前这条」的进详情工具带（编辑器上方一条安静的带：背景浅一档、按钮次要起步，唯一主按钮是交付动作如「复制到公众号」），动「集合」的进列表面板（＋新建、保存、点项打开），动「应用」的进导航栏
- **预留分区**：未来分区用占位页先声明导航位置，不等做完才出现
