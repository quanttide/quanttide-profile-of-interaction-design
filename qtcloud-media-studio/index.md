# QtCloud Media Studio 理想的交互设计体验

## 一句话

打开就是写作现场：左边草稿、中间成文、右边预览，写完一键送进公众号。

## 理想的体验

### 打开时：直接进入工作现场

- 第一眼是草稿清单和正在写的文章，没有中间页、没有弹窗
- 在写哪篇一眼可辨（清单里高亮），上次没写完的点一下就回来

### 写作时：三栏一屏

- 草稿、编辑器、排版预览始终同屏——写什么、排什么、成什么样，不用来回切换
- 切去别的分区（图文、视频、设置）再回来，稿子原样还在

### 交付时：主行动唯一

- 「复制到公众号」永远在标题栏，一处可点，点了就有回执
- 配好服务端后才出现「推到公众号」——没配连接就不给用户第二个按钮

### 管理时：各归其位

- 草稿的增、选、改发生在草稿清单里（点项打开、＋存为新草稿、保存写回），页面上不摆一排草稿按钮
- 设置沉在导航栏底部，与内容分区（文章/图文/视频）明确分开
- 未来分区（图文、视频）预留占位，位置从现在就定下

## 体验原则（这个应用的）

1. **列表–详情三栏**：导航栏 → 列表面板 → 详情区；列表面板通栏与导航栏同高，详情区标题栏只盖详情区
2. **列表面板承载管理操作**：增、改、选都在列表里完成，页面级按钮只留唯一交付动作
3. **设置与内容分区分离**：设置入口放导航栏底部，不占分区位
4. **预留先于开发**：未来分区先占位声明结构，不等做完才出现
